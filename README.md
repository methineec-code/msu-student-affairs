# ระบบกิจการนิสิต มหาวิทยาลัยมหาสารคาม

ระบบเก็บคะแนนกิจกรรมนิสิตด้วยการสแกน QR รองรับ 3 ภาษา (ไทย / English / 中文)

เว็บไซต์: https://stellar-concha-f6cf8f.netlify.app

---

## โครงสร้างระบบ

```
Netlify (หน้าเว็บ)  ──API──▶  Google Apps Script (หลังบ้าน)  ──▶  Google Sheets (ฐานข้อมูล)
```

| ส่วน | ทำหน้าที่ |
|---|---|
| Netlify | แสดงหน้าเว็บ รองรับกล้องสแกน QR ติดตั้งเป็นแอปบนมือถือได้ (PWA) |
| Apps Script | ตรวจสอบรหัสผ่าน อ่าน-เขียนข้อมูล ควบคุมสิทธิ์ |
| Google Sheets | เก็บข้อมูลนิสิต เจ้าหน้าที่ กิจกรรม และประวัติการสแกน |

---

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก เลือกเมนูและภาษา |
| `student.html` | หน้านิสิต — คะแนนสะสม ประวัติกิจกรรม Portfolio เปลี่ยนรหัสผ่าน |
| `staff.html` | หน้าเจ้าหน้าที่ — จัดการกิจกรรม ทะเบียนนิสิต รายงาน อันดับคะแนน |
| `scan.html` | หน้าสแกน QR ใช้ได้ทั้งนิสิตและเจ้าหน้าที่ |
| `admin.html` | หน้าผู้ดูแลระบบ — จัดการเจ้าหน้าที่ ประกาศ ตั้งค่าระบบ ประวัติการใช้งาน |
| `manifest.json`, `sw.js`, `icon-*.png` | ไฟล์สำหรับติดตั้งเป็นแอป (PWA) |
| `_Code.gs.backup.txt` | สำเนาโค้ดหลังบ้าน Apps Script |

## กลุ่มผู้ใช้

| กลุ่ม | เข้าสู่ระบบด้วย |
|---|---|
| นิสิต | อีเมลมหาวิทยาลัย · รหัสผ่านเริ่มต้นคือรหัสนิสิต |
| เจ้าหน้าที่ | อีเมลเจ้าหน้าที่ · รหัสผ่านที่ admin กำหนด |
| ผู้ดูแลระบบ | บัญชีเจ้าหน้าที่ที่มีสิทธิ์ `admin` |

ล็อกอินครั้งเดียวใช้ได้ทุกหน้าภายในแท็บเดียวกัน ปิดแท็บแล้วต้องเข้าใหม่

## การแก้ไขและนำขึ้นเว็บ

**แก้หน้าเว็บ** — แก้ไฟล์ใน repo นี้ แล้ว commit → Netlify จะ deploy อัตโนมัติภายใน 1 นาที

**แก้หลังบ้าน** — แก้ `Code.gs` ใน Apps Script แล้ว:

```
Deploy → Manage deployments → ✏️ → Version: New version → Deploy
```

> ⚠️ อย่าใช้ **New deployment** เพราะ URL จะเปลี่ยน ทำให้ทุกหน้าเรียกหลังบ้านไม่ได้
